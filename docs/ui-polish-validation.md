# UI/UX 정리 검증 — 2026-09-04

이번 작업은 기존 시스템의 표시·접근·피드백 개선입니다. 새 경제, 스탯, 의존성, 음원은 추가하지 않았습니다. 이전 작업의 미커밋 변경을 보존했고 커밋/배포하지 않았습니다.

## 현재 UI 문제 분석

- 프론트: 이전 nth-child CSS가 장부와 향후 메뉴를 숨겼고, 체크인 버튼이 위험 액션처럼 붉었습니다.
- 객실: 화면마다 별도의 방 표시를 사용해 이름·파손 이유가 누락되었습니다.
- 주민: 목록의 문자 아바타, 인원수로 계산한 식량 예측이 실제 개별 소비와 맞지 않았습니다.
- 시설: 공간 대신 같은 중요도의 작업 목록이 길게 나열되었습니다.
- 야간: 이동 위치·시설 해금·담당자 정보를 한 공간에서 비교하기 어려웠습니다.
- 장부: 기록과 호텔 현황이 분리되었고 명칭이 혼재했습니다.
- 시스템: 저장 성공 확인 없이 성공 문구가 표시될 수 있었고, 같은 손님 시점으로 불러오면 대사가 비었습니다.

## 디자인 시스템 변경

- 기존 어두운 녹색/검정, 황동색, 호텔 서체 유지. frontend-design 지침에 따라 새 장식보다 행동 계층을 먼저 정리했습니다.
- 기본 버튼 최소 40px, 주요 버튼 48px 이상. 체크인/진행은 황동색, 파괴적 행동은 절제된 붉은색.
- 키보드 포커스 테두리, 배경 dim과 포커스가 제한되는 ESC Dialog 적용.
- 자원 증감은 이득/손해, 시간 경과는 중립으로 구분. 범죄 위험 감소는 긍정으로 표시.
- 기존 lucide 아이콘과 캐릭터 이미지 재사용. 불필요한 화려한 효과는 추가하지 않았습니다.

## 편의 기능

- ESC 열기/닫기, 포커스 복귀. 새 게임은 ESC에서 제거하고 기존 타이틀 확인창 유지.
- 수동 3슬롯 및 자동 저장 접근 유지. 수동 슬롯에 DAY/주민/사용·개방 객실/최근 기록/저장 시각 표시.
- 수동 덮어쓰기·불러오기 확인, 중복 입력 방지, 실제 쓰기 실패 안내. 손상된 수동 기록은 불러오기 거부.
- S 저장 메뉴, J 장부, 프론트 1/2/3, 야간 시설에서 4 지도 복귀. 입력칸/조합키/모달 간섭 방지.
- 큰 글씨, 움직임 줄이기 설정 및 분류별 도움말.
- 음향은 기존 음소거 상태와 이벤트 연결점만 준비. 실제 새 효과음이 재생된다고 주장하지 않습니다.

## 그래픽 개선

- 프론트 배경과 캐릭터 기존 자산 유지.
- 객실: 주민 초상, 실제 이름, 파손 종류, 개방/점유/복구 상태를 공통 렌더러로 표시.
- 야간: 층별 30개 방과 시설을 선택하는 호텔 지도. 해금 날짜·이동 시간·현재 문제·발전기 담당자/자동화 표시.
- 시설 상태가 허용하지 않는 이동은 비활성화하고 시간 부족 설명 제공.
- 실내·주야간의 새로운 배경 삽화는 만들지 않았습니다. 공간 지도는 기능적 배치도이며 사실적인 실내 일러스트가 아닙니다.

- 저장 실패의 거짓 성공 안내 → 성공 여부를 실제 저장 결과와 연결.

## 남은 개선사항

- 빌드 JS 약772.7KB(압축252KB), CSS 약284.9KB. 500KB 청크 경고는 남습니다. 기능별 지연 로딩/중복 CSS 정리가 필요합니다.
- 실제 효과음 파일과 사운드 믹싱은 미구현. 이벤트 연결점만 있습니다.
- 시설별 정상/경고/정전 배경, 복구 전후 객실 환경, 낮/밤 프론트 조명 자산은 후속 아트 작업입니다.
- 작은 화면은 세로 스크롤과 객실 가로 스크롤이 필요합니다. 실제 터치 기기 장시간 테스트는 하지 않았습니다.
- 기존 고급 관리 상세의 긴 설명과 일부 원시 수치/용어는 추가 정리가 필요합니다.
- 희귀 야간 사건·다수 주민·후반 엔딩의 모든 조합까지 시각 검증한 상태는 아닙니다.
- 현재 결과는 로컬 미리보기에만 반영했습니다. 별도 Sites 대상이나 GitHub Pages로 배포하지 않았습니다.
